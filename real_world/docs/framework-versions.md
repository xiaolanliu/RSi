## 新框架提供的能力

- `phase`：组合有限的原动作，统一留存请求、结果和动作后观察；重复同一请求不自动重放已开始动作，观察失败可以单独重试。
- `client`：按服务器档案调用，统一传输结果和三视图，分别报告动作、观察、SSH与文件交付状态。
- `report` / `--summary`：保留实测位姿、夹爪、故障、时间和证据路径，任务是否完成由上层判断。
- `geometry` 与标定模块：共用逐帧深度、刚体换算、ChArUco检测和手眼求解，参数按现场独立保存。

原8个 primitive 和相机 IPC 保持兼容，阶段停止覆盖当前步骤及后续步骤。具体命令以 [primitives.md](primitives.md) 为准。`schema_version` 是文件格式版本，不是程序发布版本。
