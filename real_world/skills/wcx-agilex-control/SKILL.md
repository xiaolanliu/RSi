# AgileX 多服务器观察与操控

## 先选择服务器

先读 [服务器选择与共用范围](references/servers.md)，从用户本轮 IP/服务器 ID 或同一任务已明确的目标选择一个现场。不要默认选旧服务器，不因连接失败自动换机；目标仍不明确时才询问。连接和验证级别以 [servers.json](../../config/servers.json) 为入口，不能把档案当实时状态。

| 目标 | 按需读取 | 当前已记录的验证范围 |
|---|---|---|
| `10.169.21.56` / `agilex56` | [本站接入与实测](references/site-agilex56.md) | 17模块、8原入口；带阶段说明的真实录像；双臂/夹爪/RGBD、ACE书写及五列城墙轮廓实测；毛巾整齐度、精密对齐与复现未验收 |
| `10.169.21.38` / `panfeng38` | [Piper X 接入与实测](references/site-panfeng38.md) | 全部 8 个入口及共用阶段框架已部署；CAN、双臂上抬约 20 cm、RGBD、双爪抓放、拉开抽屉和红绿刀头分拣实测 |
| `10.169.21.1` / `houzhi1` | [第三套平台与共享接口](references/site-houzhi1.md) | 全部 8 个入口已部署；使能、正常恢复、双臂同步上抬约 20 cm、夹爪与 RGBD 有实测 |

各现场共用本技能和 [src/agilex_control](../../src/agilex_control) 中的通用实现，各自保留连接、型号、设备绑定、运行配置和证据。`config/site.json` 仅属于 `agilex56`；`houzhi1` 使用本站 control 配置；`panfeng38` 使用 `control-piperx-20260913.json` 的独立 Piper X 几何。三站 RGBD 共用原有 cameras.py。按本站支持范围调用，不能借用另一台参数或能力结论。

新增服务器或机械臂时读 [扩展接口](references/extending.md)：服务器选择按档案字典扩展，现有 primitive 契约保持兼容；同协议设备经核验后共用实现，其他型号在驱动层适配。

换设备、适配驱动或引用旧数据时，先读 [复用边界](references/portability.md)。共用算法和接口不代表实体参数、驱动语义或实时状态可以复制。相机、机械臂几何/零点/限位、工具/负载、标定和场景目标按实体独立；缺项保持未知，不从其他设备补用。新参数另存版本，不覆盖已有参数；本次部署共享源码时不得夹带覆盖现场配置、标定或运行目录。

## 共用工作流程

检查或对齐版本时读 [实际源码版本与部署](../../docs/framework-versions.md)。包版本号 `0.1.0` 不足以区分框架代次；对照逐文件哈希及本站验证记录。技能权威副本在本地，远端副本可能过期；算法版本一致不代表标定和现场参数可以共用。

已有授权继续有效，最新停止指令优先；不因文档再次询问已授权动作。技能改造、代码部署和历史成功记录本身不代表新任务的动作目标。用户已允许独立进程和复用工具，不要求依赖旧5555/5556；具体任务服从当前会话指令。

模型负责看图、选择目标和决定下一步；工具负责稳定采集、有限轨迹和实测结果。

观察、移动、双臂协作、夹爪和停止均优先调用下述已有 tool。新现场只补独立参数；已有实现满足需求时，不另写本站控制器、观察脚本或重复封装。确有协议差异时才在共享驱动边界做必要适配。

正常流程为：

1. 核对选定主机、现场配置、物理臂角色、相机占用和控制进程，读取完整当前状态。不能按 CAN 接口数量或枚举顺序推断左右臂/主从拓扑。
2. 观察 RGBD 和反馈，确认坐标系与物体，再规划动作。切换服务器、机械臂或相机安装后，重新验证相关几何。
3. 调用选定服务器、选定机械臂的工具；观察图像、实际位移、夹持与故障，判断任务结果。发送成功、`ok:true` 或反馈正常都不是运动/任务完成证明。

若现场有现成服务则按本站契约复用；相机采集和动作调度分离，不争用设备。原生 ROS 与独立 CAN 写入器不能同时控制同一总线。只检查能力/观测时，不用 move、自动使能或模式切换来试连通性。

首次接入、重启/重插、使能或恢复时，统一读取 [CAN 初始化、使能与运动准备](references/initialization.md)，配合本站档案中的型号、参数与实测差异执行。

## 通用 primitive 契约

读取 [工具契约、部署与示例](../../docs/primitives.md) 和 [tools.json](../../config/tools.json)。这些是通过 SSH 调用的 Python/JSON CLI，尚未注册为 Codex 原生 MCP。使用选定现场的 Python、项目与 `--config`；部署状态未满足时先按该现场的接入档案处理。

- `get_state`：被动读取配置中的 CAN 接口，返回时间戳、机械臂反馈和观察到的控制帧；不依赖相机或运动学。新平台可先接入此接口，物理角色未核验时按总线名返回，不猜左右。
- `observe`：共用相机服务读取 RGBD、逐相机内参和深度比例，默认同时读取机械臂反馈。本站臂反馈未接入时配置明确关闭该项，返回 `states:null` 和 `missing_modalities:["arm_state"]`；不把读取失败自动降级为成功。相机之间不保证同步。
- `move_left` / `move_right`：固定该现场对应执行臂；输入关节角或该臂基座下 link6 XYZ/RPY、运动时长，可 `dry_run:true`。
- `move_both`：同一服务器上两臂共享轨迹时钟；同 tick 依次写 CAN，不是硬件原子同步，也不是跨服务器同步。两爪夹同一物体时不能以两个并行单臂调用代替。
- `set_gripper_left` / `set_gripper_right`：指定开度 mm 与驱动力矩 N·m，返回实测开度/力矩/FOC；接触物体未闭到零可能正常，提起后用图像验证。
- `stop`：停止选定服务器本工具的后续目标；不自动撤回、失能或复位，不能撤销硬件已接收的目标。再观察实际状态；用户要求全部停止时覆盖本任务实际启动的全部服务器。

新逻辑动作或观测使用新的证据身份；已有阶段的传输重试或仅重试观察，保持原请求与阶段目录，不能换目录重放动作。新日志和标定归入带服务器身份的 evidence/experiments；不把任务坐标硬编码进工具。历史失败动作脚本仅作证据，可复用实现集中在共享模块。

需要减少动作间的重复取图、计算和调用时，按 [通用调用与阶段契约](../../docs/primitives.md) 使用 `agilex_control.client`：复用原工具执行有限阶段，返回关键反馈和本地三视图。`agilex_control.geometry` 只做本帧 RGBD、标定与显式接触点的几何换算。阶段结束后据新观察判断下一步，任务结果不由底层 `ok` 自动判定。

## 单位与执行边界

- 关节/RPY 为度，位置为毫米。当前反馈和 FK 对应各型号末端 link6/法兰，非已标定指尖。`.56` 历史 URDF 的135.8 mm偏移指向其指关节框架，不能复制为 Piper X 或其他工具的 TCP。
- 机械臂 move 只向选定执行臂写模式和六关节目标。夹爪只发送0x159（执行使能位1、零点位0），不清错误；FOC位7是回零标记，0xC0不应当作故障。
- 高随动模式速度比例不提供实际限速。轨迹按已发送tick推进，不因主机阻塞追赶到远处目标；合理选择运动时长。
- 保留实际设备故障、缺失/过期反馈、驱动异常、控制权冲突和本站已核验SDK关节边界。故障后先保存完整状态，再决定恢复方法；不重新添加用户已要求移除的任意瞬时精度、单步或速度中止阈值。
- 不自动改固件、零点、关节限位、碰撞保护或后部示教配置。任一站点首次接入都需核对其驱动初始化副作用和控制路由。
- 局部拟合误差不是机器人绝对定位精度。不能跨服务器、跨臂复制标定或现场坐标；同一模型也要核对相机、基座、工具和误差元数据。

## 按任务读取经验

- 按参考轮廓搭建积木与逐层支撑验收：[积木搭建流程](references/block-stacking.md)。先规划支撑，再依据每次实际落点更新目标；空抓、推移和持物变化必须重观测。
- 真实动作分段录像、去除推理等待和三路上下拼接：[动作录像 skill](../wcx-agilex-action-video/SKILL.md)。复用原相机服务与阶段入口，服务部署和配置启用按现场核验。
- 持笔书写与另一臂压纸：[书写流程](references/pen-writing.md)。区分笔尖与夹具附件、每次换抓后重新验证接触，用撤离后的实际墨迹验收。
- 多相机手眼、相机到双臂基座标定及场景变化后复核：[可复用标定流程](references/calibration.md)。采集/移动复用原 primitive，检测/求解共用模块，实体参数分别保存。
- 局部几何、接触中心与物体目标到 link6 的换算：[local-geometry.md](references/local-geometry.md)。包含 `.56` 历史局部映射及共用几何关系；按各自实体和验证范围使用。
- 叠杯、套杯或把倒扣纸杯套成一摞：[倒扣杯套叠任务](references/cup-nesting.md)。按实际夹持高度对中，分别验证接触、试提、持稳、套入和撤离后稳定；复用原工具和共用几何。
- 一臂固定瓶身、另一臂旋开瓶盖：[双臂拧盖任务](references/bottle-opening.md)。区分瓶轴与工具轴，验证相对转动、轴向脱离和回腕重抓；复用原工具，物理参数按现场重测。
