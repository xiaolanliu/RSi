# 花茎等细长物体的抓取与插入

适用于需要将细长物体竖起、送入开口并释放的任务。沿用 observe、对应臂的 move 与 set_gripper；具体目标留在任务证据，工具内部不增加花材坐标或特例。左右算法相同，各自使用基座、反馈和图像，观察臂也需要留出实体空间。

## 根据实物决定下一步

1. 观察花头、茎尾、可夹持段和瓶口。根据夹点到茎尾的距离估算翻转与插入需要的高度；靠近茎尾能降低所需抬升，但仍需留出可插入长度。link6 不是指尖 TCP，135.8 mm 也不是已标定的抓持点。
2. 用开闭变化识别活动夹指，让闭合方向横跨花茎。闭合后提起，结合开度、力矩反馈和花茎随动确认夹持；闭合过程本身可能改变茎轴方向。根据**提起后的轴向**规划翻转。
3. 先转到中间姿态，复查物体相对夹爪是否滑动，再竖起。关节姿态到位不等于花茎到位。本次 0.3 N·m 设定下滑转约 60°，1.2 N·m 在重新抓取后保持住了这两枝；这些设定不代表标定指尖力，也不应作为所有花材的固定默认值。
4. 从能够看清茎尾、瓶口和已有花头的侧面观察。调整相机臂前，把相机、张开的手指和线缆一起视为障碍物；本次观察臂前伸过近，撤远仍能完成观察。右臂夹具曾接触第一枝花头，抬离后才调整进入方向。
5. 先在瓶口上方对齐，分段接近并观察。细茎、黑指深度为 0 或非零背景深度都常见：检查沿目标的连续性、邻域与遮挡关系。确实测到前景时，可比较茎尾与瓶沿平面；否则结合两个 RGB 视角，不把背景深度补成物体深度。
6. 确认茎尾进入瓶口后张开。花头/叶片可能搭在手指上；保持张开，沿脱离方向退出，避免直接上抬带出花或大转腕带动瓶子。退离后再收臂，复查两条花茎、花瓶稳定和空夹爪。

## 接近竖直时的姿态计算

RPY 只作为输入/显示；接近 pitch ±90° 时不能从固件/旧 SDK 的截断 Euler 重建真实旋转。共享 `Kinematics.transform(q)` 提供原始旋转，求解已修复。IK 未收敛只说明当前求解没找到满足边界的解，不等于全局不可达；先核查数学和当前状态，不通过放宽硬件限位、伪造种子反馈或增加专用执行器绕过问题。

SDK modified-DH 私有接口是当前明确依赖。SDK 升级后运行 `tests/test_kinematics.py` 的近奇异与普通姿态回归；没有实际 SDK FK 文件时测试会跳过，不能报告为实测通过。约 60° 的花茎滑转与此次 Euler 数值问题属于两个不同原因。
