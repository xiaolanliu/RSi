# 倒扣杯套叠任务

用于将能够相互套入的杯子逐只套成一摞；已有实测对象是倒扣的锥形纸杯。先从当前图像确认杯型、朝向、数量和目标杯摞，不能把“叠杯”默认解释成杯底支撑的高塔，也不把倒扣纸杯流程直接用于不同接触方式的杯型。

本页是 [wcx-agilex-control](../SKILL.md) 的任务层，沿用其中的选站、实体参数、授权和停止规则。几何换算读 [local-geometry.md](local-geometry.md#有外参时的夹持与套入几何)，标定状态读所选现场档案；不另建硬件入口或复制控制器。

## 任务数据与工具分工

从新观测建立本次杯子与杯摞的身份、杯轴、杯口中心、计划夹持高度的截面、桌面和障碍物。场景中的“前杯”“后左杯”等只是本次索引。杯子被推移、转动、滑落或已套成更高杯摞后，重新定位受影响对象，不重放历史杯坐标、接触偏移、夹持力矩或末端角度。

- `observe` 提供当前 RGBD、实测末端/夹爪反馈和时间戳；模型据图判断杯子与夹爪、桌面、杯摞的关系。
- 任务层选取杯口或接触点目标，共用几何将它换成所选臂的 link6 目标，再交给原 `move_left/right`。dry run 检查可达性；还要据当前场景检查夹爪和整杯的沿途净空。
- 原 `set_gripper_left/right` 负责开度与驱动力矩。开度、力矩、FOC 辅助判读接触，不能单独证明物体已夹牢；驱动 N·m 不是杯壁上的夹持力。
- 共用阶段记录保存本次请求、实际反馈、观测来源、假设是否成立及下一步决定。阶段结束后再决定后续有限动作；不要一开始把抓取到放置整条路径排队执行。

选择能看清本阶段关键关系的视角：对中看两侧垫面与杯身，试提看杯口与桌面的间隙，搬运看杯子相对夹爪是否滑移，套入看两杯轴线与接触，撤离后看杯摞稳定。另臂可保留观察视角，不能把固定观察位或某一路相机编号写成任务默认。

## 对中与建立持物关系

圆杯侧夹应在**实际夹持高度的杯身截面**对中，使两块有效接触垫的合拢线通过该截面圆心。倒扣杯的白底可帮助定位杯轴，但白底直径、可见指尖中点和内侧垫面接触带是不同几何量；斜着接近时不能将它们直接互换。杯壁直径随高度改变，不能用窄端白底直径设置任意高度的接触位置。

先在张爪状态对中，再接近计划接触带，观察杯身是否进入两侧有效垫面。边缘深度可能混入桌面或夹爪；缺失或矛盾的几何保持未知，通过当前图像或其他视角补充。杯子被推动后应重新对中，不能通过重复闭爪或增大力矩掩盖几何偏差。

接触后的小幅试提确认成功，才用实际末端位姿和当前杯口/杯轴建立物体到 link6 的暂定关系，包含杯口参考点和杯轴方向。它是本次夹持假设；接触带、开度、杯壁形变和相对姿态都影响它，不能把一次成功反算的接触点发布为通用 TCP。

倾斜夹取时杯轴与 link6 轴可能不同。可从同一份停稳观测选取可见口缘点，经现有 `geometry.observation_points` 取得三维点，用 NumPy SVD 拟合口缘平面、在平面内拟合圆心，以法向估计杯轴并按杯子的实际朝向确定符号；再结合实际 FK，按 [共用点与方向换算](local-geometry.md#有外参时的夹持与套入几何) 建立局部关系并求扶正旋转。只更新杯口局部点、继续用第一只杯子的 RPY，不能保证后续杯子竖直。保存选点图像/像素来源、有效点数、平面与圆拟合残差及可见圆周范围；点少、只见短弧或口缘深度混入桌面/夹爪时保持不确定，不能把低残差当成绝对精度。发生滑移后重新估计杯口点和杯轴，两者都不能继续沿用。

纸杯白色包边有高度和曲面，不能把白色区域任意像素都视为同一杯口平面；选点须属于同一条物理圆周边界。转腕后应以新观测复核杯轴与持物关系；若法向不一致，重新检查选点和相对滑移，即使局部短弧拟合残差很低，也不能据此宣称杯轴准确或精确扶正成功。

## 阶段验收

| 阶段 | 需要观察到的结果 | 结果不支持下一阶段时 |
|---|---|---|
| 接触 | 杯身位于两侧垫面之间，闭爪后有合理的接触形态与反馈 | 核对接触高度和对中；杯被推动则重新定位 |
| 小幅试提 | 杯口与桌面出现间隙，杯子随夹爪运动 | 仍与桌面接触不算抓取成功；恢复到可观察的稳定状态后检查几何 |
| 持稳搬运 | 分段运动后杯子仍在夹爪内，杯口/杯轴相对夹爪关系保持，整杯净空足够 | 滑移或脱落使旧持物关系失效，取消依赖它的剩余目标 |
| 对准与套入 | 当前杯口与目标杯摞轴线、相对高度支持套入，接触后运动仍符合预期 | 卡住、推动杯摞或提前脱离夹持时重新判读支撑关系，不继续原下降目标 |
| 释放与撤离 | 杯子已由目标杯摞支撑；开爪、撤开后杯摞仍保持 | 区分未套入、夹爪仍支撑或杯子自行滑入，按实际状态恢复 |
| 结果复查 | 所需数量的杯子套成一摞，夹爪已离开；新的结果帧仍显示稳定 | 报告当前结果和未完成项，不用无故障反馈代替视觉验收 |

试提距离、搬运分段、接近角度、开度和力矩由当前杯型、接触情况、可达空间与观测决定。短试提成功只验证该段离桌，不证明较长搬运仍会持稳；不能从一次改变多个因素后的成功，断言其中某一个参数单独解决了问题。

## 搬运、套入与恢复

倒扣杯用宽杯口中心和杯轴规划跨越障碍及套入方向。移动和转腕时按共用几何更新杯口边缘、杯壁、夹指与腕部的扫掠空间，不能只抬高 link6 就断言杯口已清障。目标杯摞每加入一杯后重新测量，下一次套入高度不能沿用上一摞的值。

在杯摞上方先核对轴线与口缘净空，再根据新观测逐段接近；接触后是否继续下放、调姿或松爪取决于当前支撑关系。纸杯形变和摩擦尚未建模时，不把更深的下降目标当成套入证明，也不自动通过加力强行套入。

图像显示相对运动、或夹爪开度/接触反馈改变而不再支持持物假设时，先取消依赖旧物体关系的后续动作并观察。杯已落回桌面就按新位置重新抓取；杯已滑入杯摞，则核对其支撑与稳定，选择开爪、撤离等有限动作，不追赶杯子或继续预排的下降、扶正。

失败重试应针对新观测支持的原因，例如接触带偏差、对中错误或持物关系变化。同类失败再次出现而没有新的几何或接触依据时，停在可观察的稳定状态，报告仍缺少的条件；不要重复同一闭爪和抬升。恢复和重试仍受当前会话授权与最新停止指令约束。

## 已有实测与边界

[10.169.21.1 的本轮实测](../../../evidence/2026-09-13/host-10.169.21.1/cup-nesting-framework-1757/README.md)已通过通用阶段调用原工具，将三只倒扣纸杯套成一摞；开爪撤离后75.08秒的 [新帧](../../../evidence/2026-09-13/host-10.169.21.1/cup-nesting-framework-1757/35-stability-check/observation-000/d435i_071316/rgb.jpg)仍稳定。没有掉杯或重抓，第三杯第一次短试提经深度和补提复核后才搬运；不能排除小幅就位滑动，两只搬运杯均主动开爪后由重力落稳。白色包边局部拟合的法向在转腕后复查不一致，不记为精确杯轴测量或扶正验证。

[首轮记录](../../../evidence/2026-09-13/host-10.169.21.1/cup-stacking-154501/README.md)也达成最终套叠，但包含前四次试提失败、一次第三杯搬运滑落和重抓；末次第三杯提前脱离夹持并自行落稳，不能称为精准受控放置。这些是该轮历史过程，不能混作本轮结果。

两轮均使用本站外参候选作初定位，再据新 RGBD 纠偏；候选仍为 `accepted_for_control=false`，打印板尺寸暂估，绝对定位和 TCP 未完成计量验证。历史接触偏移、杯尺寸、目标姿态、力矩及结束坐标仅保存在证据中，不是本任务的通用默认。后续任务另存阶段结果、实际几何与失败证据，分别报告最终结果、受控过程和仍未验证的能力。
