# 局部几何校正：复用、重新采样与验证

用于复用局部视觉位移映射，或将本站标定转换成实际接触、搬运和套入目标。下述历史映射与采样数值属于 `agilex56`；其他现场的外参与 TCP 验证状态按本站档案判断。仅询问能力/复用时只检查记录，不自动移动或开闭夹爪。实际采样继续遵守会话已有动作权限与最新停止指令。

## agilex56 历史局部映射与适用条件

该现场历史结果是 [hd_local_translation_model.json](../../../experiments/hd_local_translation_model.json)，保留原始矩阵和四组配对点，新增的来源元数据来自已保存观测。不要把该文件中的 `target_fk_xyz_mm`、`desired_surface_point_mm`、`delta_fk_mm` 当成下一次任务目标。

| 项目 | 本次范围 |
|---|---|
| 执行臂 | 前右臂 `can_right`；左臂没有这套实测标定 |
| 相机 | 前视 D455，序列号239622301704，1280×720，深度对齐前视RGB |
| 特征 | 闭爪状态下同一个可见活动夹指表面；不是固定尖支架、相机壳或严格定义的抓取中心 |
| 姿态 | 参考RPY `[180,0,-56]`°附近；采样有小幅姿态差异，误差包含其影响 |
| 采样范围 | link6各轴约x307–331、y268–295、z136–168 mm；仅为采样包围盒，不是保证精度的工作区 |
| 验证程度 | 同一任务内帮助抓取四块；红小块/长条一次成功，浅蓝首抓失败后纠偏成功。未验证跨会话重复性，没有独立留出点测出的定位精度 |

相机、基座、末端附件与特征关系一致时，可把结果作为新任务的初始估计。相机/基座重新安装、附件变化、切换另一臂、姿态明显变化或移到新的工作区域时，需要重新观测、验证，必要时重采样。左右可以共用算法，不能复制或镜像右臂矩阵冒充左臂标定。

## 下次先检查什么

1. 调用observe，保存新RGBD和实际双臂状态。比较相机序列号、分辨率、安装情况、目标臂、夹爪状态和姿态。只凭相同序列号不能证明相机没有移动。
2. 使用每帧自己的内参、畸变参数和深度比例。本次同一序列号/分辨率下fx从641.48到642.00有小幅变化，不能把内参数值完全相等当作唯一兼容条件；分辨率变化后也不能将旧像素直接乘二。
3. 从已保存开闭证据或当前允许的开闭观察确认活动夹指。模板高分不能代替特征身份检查。黑指表面的0深度、边缘混合值、腕图后方桌面都不能补成指尖。开爪后闭爪模板不再代表同一表面位置。
4. 在实际任务允许的空闲空间检查局部位移响应，再决定是否复用。变化量、姿态和工作区域都匹配且误差满足当前抓取几何要求时，可保留原映射作为初值；数据不支持时重拟合。误差判断属于几何验证，不新增用户已移除的运动中止阈值。

## 重新建立局部映射

**采样。** 使用现有move与observe，记录基准点及三个独立平移方向。保持工具姿态和被观察的物理特征尽量一致，用实际link6反馈作为机械臂坐标，不能用请求目标代替。位移根据当前可观测空间选择；本次约20–25 mm只是历史采样尺度，不是固定步长或限制。有更多有效样本时一起拟合，并另留未参与拟合的验证观测。

**坐标。** 每个样本都需要成对的三维点：`arm_points_mm`为所选臂基座下实际link6 XYZ，`feature_points_mm`为同一物理特征在同一坐标系中的位置。对齐深度用该帧RGB内参反投影。新采样可以直接用前相机三维坐标作feature坐标，不必先套不可靠的历史外参；必须写明坐标系和单位。

旧模型的feature点已使用历史外参转换到“历史右基座坐标”。其J不能直接乘相机坐标里的误差；必须保持相同坐标约定，或从原始点重新拟合。差分会消去历史外参的平移项，因此旧平移一致性检查没有验证绝对外参平移。

**拟合。** 使用 [fit_local_translation.py](../../../scripts/fit_local_translation.py)，只需要NumPy，无设备访问：

```bash
python scripts/fit_local_translation.py measurements.json candidate_model.json \
  --validation held_out_measurements.json
```

两个输入都使用成对Nx3数组，并在 `frame_contract` 中描述坐标系、物理特征和单位。拟合输入至少四组、平移方向需满秩；验证输入为另外采集的点。用新输出路径保留前次结果。脚本不会替你识别特征、采集数据、设置运动目标或自动批准精度。

模型是 `f = f0 + J @ (b - b0)`。对于同一特征的当前实测点，纠偏量可由 `Δb = solve(J, f_target - f_current)` 得到。这里的f是被跟踪特征，不自动等于夹持中心；物体中心与所需夹指位置之间还需接触几何或实际抓取参考。

**独立验证。** 看未参与拟合的新观测中，预测特征位置与实际特征位置的差异，同时核对姿态变化和深度质量。四个非共面样本足以精确拟合一个仿射映射，因此训练残差接近零不证明精度；J的条件数约1.27也不是毫米级误差承诺。没有独立点时明确标为“候选局部映射”，不能宣称完整标定完成。

**应用与记录。** 先预抓取并观察，下降/合爪后结合非零夹持开度、力矩和提起后的物体随动判断。被推移的物体重新定位，不重放旧目标。成功抓取位置可作经验参考，但不能把此前“期望特征位置”视为已测量的真实接触TCP。

保存相机序列号、原始逐帧内参/RGBD、目标臂、实际位姿与夹爪状态、特征身份/像素对应、坐标系、采样点、矩阵、训练残差、独立验证结果、适用范围和失败案例。数值与证据归入experiments/evidence，控制器继续只接收任务参数。

## 有外参时的夹持与套入几何

标定用于把本帧 RGBD 点变到所选臂基座，原 `move_left/right` 仍接收 link6 目标，不需重写工具。若接触点在 link6 中为 `p_L`，目标基座点为 `p_B`、目标旋转为 `R_B_L`，则法兰平移为 `t_B_L = p_B - R_B_L @ p_L`。相机外参不会自动给出接触点、工具姿态或物体尺寸；候选外参仍需在接近目标时用当前图像纠偏。

成功抓取反算出的局部接触参考可以复用作初值，但其适用性依赖实体夹指、物体形状、夹持开度与接触姿态，不能升级为通用 TCP。为任务选取可观测的物体参考点和轴线，在持物关系经图像确认后，建立同时包含**局部点与局部方向**的暂定关系。物体轴不一定与 link6 轴重合；由同一份停稳观测的基座点 `p_B`、单位方向 `a_B` 及实际 FK `[R,t]` 得到 `p_L = R.T @ (p_B - t)`、`a_L = R.T @ a_B`。

需要改变物体朝向时，求满足 `R_target @ a_L = a_B_target` 的末端旋转，再用目标点反算平移。可复用 `Rotation.align_vectors` 求当前物体方向到目标方向的增量旋转 `ΔR`，令 `R_target = ΔR @ R`。单一方向不能确定绕该轴的转角，仍按当前夹持、可达性和净空选择；不能仅固定局部点后套用另一物体的 RPY。若方向来自局部平面/轮廓拟合，应保存点来源、残差和可见覆盖范围；点少、覆盖狭窄或深度混入其他表面时保留不确定性，低拟合残差不是绝对精度证明。

改变末端姿态时，物体各点按 `p_B = R_B_L @ p_L + t_B_L`、方向按 `a_B = R_B_L @ a_L` 更新；保持法兰 XYZ 不变不代表物体参考点不动。规划检查覆盖整臂、夹指与所持物体的扫掠空间，端点 IK 成功不代表途中无碰撞。若新图像显示滑移、形变或脱离使刚体假设失效，局部点和方向一并作废，取消依赖旧关系的剩余目标，重观测后再建立几何；不能只更新法兰反馈而继续沿用旧物体关系。

杯身截面对中、杯口净空、分阶段验收和套入失败恢复见 [倒扣杯套叠任务](cup-nesting.md)；对应实体的参数和成败证据留在本站记录中。
