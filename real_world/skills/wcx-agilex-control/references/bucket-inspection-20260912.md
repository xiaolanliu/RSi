`/home/agilex/calib_result` 有四份 2026-03-08 手眼标定，但缺少相机序列号、左右基座、模式及误差标识。16:52:44 文件作为 camera→右 base 的假设，结合 FK 末端沿 local Z 延伸 135.8 mm，能把右指关节框架投到当前前图约 `(655,322)`，与右夹爪区域吻合；其他两份对左侧也近似吻合。

## 深度拟合结果

`../../../experiments/bucket_depth_geometry_readonly.py` 对单帧深度做桌面平面和桶口平面/圆拟合，输出 `../../../experiments/bucket_depth_geometry.json`。四组 RGB 桶沿 ROI 下，候选右 base 桶口中心约 `[365,193,214–217]` mm，半径 107–108 mm；距拟合桌面 207–210 mm。

桌面有效 73,146 点，平面异常值 0.31%，RMS 1.16 mm，但法向 `[-0.108,-0.080,0.991]` 与 base Z 倾斜 7.72°。桶沿深度有效率 54–59%，有效点中 20–37% 被过滤，四组 ROI 的中心差约 3.3 mm；圆径向 RMS 1.9–2.0 mm。这些是样本拟合误差，不包含旧外参系统误差，不是机器人定位精度认证。

末端 link6 和指关节框架都不能直接视作现场实际指尖。应先在可见高位重新核验投影与指尖偏移，再计划跨过桶沿；当前仅有离线高位目标，未执行。
