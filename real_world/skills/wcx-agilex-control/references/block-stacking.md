# 按轮廓搭建积木

复用 observe、move_left/right、set_gripper_left/right 与 phase；模型负责识别形状、选择支撑和看图验收。算法可复用，物体、相机、夹指和机械臂参数按本次实体测量，任务坐标只进证据目录。

## 从目标形状到支撑关系

先把参考图解释成轮廓与支撑关系。若用户只要求形状，不把颜色、字母和具体积木身份加入约束。例如城墙可表示为五列高度 `[3,2,3,2,3]`：先做两层连续主体，再加三个间隔凸起。长条可以替代连续的多个底层单元，但要核对实际长度、厚度和剩余材料数量。

用当前 RGBD 测量物体顶面、尺寸和桌面，保存来源帧及候选精度。颜色掩码会受字母、遮挡、反光与深度孔洞影响；局部矩形角度在相邻帧明显跳变或尺寸只覆盖半块时，不把它直接当作物体朝向。结合 RGB 边缘、已验证尺寸和合理顶面高度范围重新核对；下侧面点不能当顶面。

搭建前检查最高、最远列以及接近和撤离姿态的可达性。端点 IK 成功不表示整臂、相机附件、线缆和持物路径都无碰撞。需要不同末端朝向时重新计算持物关系，不通过修改关节限位获得可达性。

## 抓取与落放

1. 夹爪开口要容纳方块的当前投影宽度和已观察到的位置误差。接近、下降、夹紧、试提用有限阶段；不确定对中时，先停在物体上方观察两指位置。
2. 同时查看实际开度、力矩和提起后的物体随动。闭到零且物体仍在桌上属于空抓；物体被碰转或推移后，旧坐标失效。读取完整状态，重新观察并改变有依据的接近参数，不重复播放旧抓取。
3. 以抓紧后、物体仍受桌面支撑时的实际 FK 及物体观察建立暂定局部点和方向。闭爪过程可能推动物体，因此这仍是候选持物关系。需要转腕时按完整刚体变换反算法兰，不能固定 XYZ 只改 RPY。
4. 优先从底层向上，每块放在已有支撑上。落放时尽量让夹爪朝墙的前后开合，为相邻列留出空间；检查整个夹具与已搭部分的距离。
5. 先到支撑上方，对中后下降，松爪、垂直撤离、再让开视线。用新图像验证实物是否释放、保持稳定、形成预期支撑与轮廓。运动命令成功不等于搭建成功。
6. 依据实际落点更新列中心和支撑高度。若放置推移了邻块，需要一起更新；不能继续沿用最初网格。实测偏差可用于当前区域和姿态的下一次初值，不能写进通用控制器，也不能视为通用 TCP 或完整手眼标定。

同一物体换抓、滑移或明显转动后，重新建立持物点和方向。远处或高层需要倾斜手腕时，还要考虑方块底面的倾角、最低角点和落下后的支撑；不能只验证法兰位置。

在上层进场时，若夹具附件靠近已经完成的城垛，先抬到空处转腕，按显式持物点和完整旋转换算法兰，再重新观察。旋转时保持方块位置的端点计算不代表中间轨迹完全定点，需留出转动空间。释放后的抬升应使最低夹指/附件越过新顶面后再横移，不能刚离开方块就沿墙扫过。

软垫夹指偏在方块棱角或边缘时，松爪可能使方块侧向脱出。先用录像确定发生在张爪、下降还是撤离阶段，再调整居中程度、平面朝向、夹持力和释放净空；不要把每次失败都只归为坐标误差。轻小物体优先选择足以持稳的夹持力，试提后核验；本站某次0.5 N·m成功不构成其他物体或夹指的通用参数。相机几何拟合残差小也不能替代释放稳定性验收。

相邻同高方块可能被一起夹起。试提后核对目标及附近物体的原位置，并观察持物数量；不只检查一个颜色是否出现。近处腕图的彩色物面可能没有对应的有效深度，返回的背景深度不能作为“仍在桌面”的证据。发生数量或身份矛盾时，先在清楚视角核对随动；双块夹持不能继续执行单块放置候选。可以先放回空处，再从外侧偏移接近或分离物体，依据新的抓取重新计算相对位移。
