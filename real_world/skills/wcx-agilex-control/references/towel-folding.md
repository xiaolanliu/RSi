## 本轮新增的决策依据

- 在采样前，用实际开合图像确认接触件及闭合位置。本轮误跟踪突出灰色固定端头；四点 PnP 及留出点残差较小，仍未得到正确抓取中心，随后两次试提为空。固定支架可用于估计刚体运动方向，不能因拟合漂亮就当作 TCP。原错误拟合保留在证据中，不进入配置或默认工具。
- 黑色夹指深度缺失时，可结合固定姿态的图像运动、实际反馈、腕部图像和已确认的接触参考纠偏。接触参考与支架映射分别标注；持物点附近布面有深度，不代表该点就是夹持中心。姿态改变后重新考虑接触点偏移，不能直接套原平移。
- 第一折两侧各试提，确认同一整边随动后同步抬起、越过中线、铺放和释放。一次左侧成功而右侧为空时，只修正右抓点，未夹稳不进入翻折。高位姿超出原 SDK 范围时重新选取可达姿态，没有修改关节边界。
- 第二折前先整理工作位置，使目标落在执行臂可达范围；另一臂完全退出后再跨越桌面中部。本轮右短边单点夹持、抬高并向左翻折完成了方向变化，但留下卷起和错层，**不能升级为整齐对折的成功配方**。需要保留短边两端及各层身份，而非只看占地缩小。
- 小幅角点调整与竖直压平是事后修整。本轮改善部分边缘和鼓起，但不替代正确的夹层与折线控制。压平使用既有 move 的有限位置请求，不是已标定的力控 primitive；读取对应步骤的接触时反馈，不能只看撤离后的 phase 摘要，也不持续降低目标来补偿受阻。
- 重复角点拉动和按压仍有卷起时，本轮改夹重合端、短试提后整体悬挂，确认桌面无遗留布层且没有展开成长条，再先落自由端、逐步铺下夹持端。它改善了中央卷团，但未使四角对齐；仅可作为已折叠软物的整理候选，不作为已验证的整齐折叠方法。单点夹持会聚拢一端，后续策略需要控制边角和层身份，不能无限重复同类修整。
- 后续两点抓同一长边也曾只带起部分层：首轮为空，修正后两爪非零且边缘随动，高提时仍有下层未跟随。发现后放回、释放并撤离，未继续拉开。两点控制本身不能弥补层身份错误；未来需先建立原角点、折线及每层对应关系，再做短试提的全层验证。该次失败未固化为新的默认抓点或动作配方。
- SSH 回传中断后先核对原阶段 journal。本轮031远端已完成动作及观察，原请求、原目录续取未重放动作；再读实时状态确认。连接恢复或 ping 通不说明动作是否完成。023错误字段在阶段创建前被验证拒绝，与031回传中断是不同问题。

## 改变后续决策的教训

- 第一轮双角提起和近边向远边的翻折有图像证据；随后抓侧边中部的单点横折产生卷起、布层错位和整体拖移。夹爪有非零开度、布料随手运动、占地缩小，都不足以证明抓住了计划中的所有层或已折整齐。
- 记录抓点是角、边中点还是折线端点，以及它属于哪一层；松爪、滑移或重新悬挂后重新辨认。不能把表面褶皱的尖点直接当作原矩形的角。两角控制、折线中点与重力下垂是后续可探索的方法，本次尚未验证为成功叠毛巾流程。
- 低处平移可能拖动整条毛巾；抬高也可能展开原来的折层。观察固定部分、自由边、层的跟随和落下后的形状，不能把法兰轨迹当成布料轨迹。
- 左右承担的空间次序需要与实际抓点对应。需要换边时先铺放、撤离并重新分配抓点；此次左臂去抓右侧自由角时，前臂及腕相机附件进入了另一臂的空间。端点 IK 成功只说明运动学可达，不包含相机、支架、线缆或整条插值路径的碰撞验证。
- 靠近另一臂/附件时，在接近阶段保留观察边界，检查两臂实测状态后再下降或合爪。此次把悬停、下降、合爪放入一个 phase，直到全部完成才看到未受控右臂的偏移，反馈来得太晚。常规开阔工作区仍可使用有限 phase，不一概拆散所有动作。
- 检查非本次控制臂的反馈。此次右臂在左爪合上前已位移约47 mm、pitch变化约27°，两臂仍无错误码。静态无报错和本臂命令路由正确，均不能排除机械接触；也不能将此事件解释为普通目标误差后继续挤压。
- phase 最终摘要可能展示撤离后的状态，不能据此判断中间铺放步骤已达到目标。需要时读取对应 step result：本次一处铺放目标z115 mm而实测约130 mm。出现接触/受阻线索时重新观察，不用持续降低目标来补偿。
