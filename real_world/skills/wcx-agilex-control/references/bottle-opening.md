# 双臂旋开瓶盖

用于一臂固定瓶身、另一臂夹持并旋开螺纹瓶盖。先确认连接方式、旋松方向、瓶身支撑和可夹部位；按压解锁、卡扣、连体盖等结构需要依据实际机构调整，不能只重复旋转。沿用 [主技能](../SKILL.md) 的选站、授权、停止与硬件契约，几何复用 [local-geometry](local-geometry.md#有外参时的夹持与套入几何)。本页不提供固定坐标、夹持力或回转角默认值。

## 先解决三个物理条件

瓶身需要承受反向转矩；瓶盖需要相对瓶身转动；螺纹旋出时需要沿瓶轴获得位移。工具回转、夹爪闭合或目标到达都不能单独证明这三个条件成立。

根据两臂实际可达空间分配固定臂与旋盖臂，不固定为左手或右手。瓶底可由桌面支撑时优先利用支撑，夹住能抗转且不易压坏的瓶身部位，并给另一手、腕相机和线缆留出回转空间。瓶子若靠近工作区边缘，先用原工具的 dry run 检查夹盖、有限旋转、松开回腕及取盖撤离的可达性；需要挪瓶或更换角色时，在两手形成接触约束前处理。

旋盖臂的两块有效接触垫应跨过**瓶盖在实际夹持高度的直径**，避开同时夹住瓶颈、止脱环或瓶肩。相机壳、可见指尖和内侧指垫不是同一点；标定给出相机到机械臂的关系，不会自动给出实际夹持中心。夹具倾斜时尤其不能把瓶盖像素中心直接当成 link6 目标。

## 本次几何与工具分工

用 `observe` 建立本次瓶身、瓶盖、瓶轴、接触带、桌面和障碍物的关系；按实际实体选择相机参数与外参。优先使用能看到接触关系的腕视角和能区分瓶身转动的全景。黑盖或过近表面的0深度不能补成桌面深度；换视角、选同一物体上的有效测量，或明确保留几何不确定性。

`geometry.observation_points` 负责本帧像素/深度到指定臂基座的换算；实际 FK 与 `point_in_link6`、`link6_target` 负责局部接触点和目标法兰的转换。固定臂的目标仍在它自己的基座中，不能复制旋盖臂坐标。夹盖成功后记录该次接触参考和瓶轴；它们在滑移、重抓、推瓶或夹持高度变化后须重核，不能作为通用 TCP。

若本次瓶轴在旋盖臂基座中为单位向量 `a`，轴上接触参考为 `c0`，夹持开始的实际旋转为 `R0`、局部接触点为 `pL`，则有限旋转目标为：

```text
R(theta) = Rot(a, theta) @ R0
c(theta) = c0 + s(theta) * a
t(theta) = c(theta) - R(theta) @ pL
```

旋转和目标点均在同一基座中，`s` 为有依据的轴向旋出位移。通过已有矩阵/旋转计算与 `geometry.link6_target` 得到原 move 的 XYZ/RPY，不新写驱动。只有瓶轴确实平行基座Z且旋转约定匹配时，改 yaw 才等价于绕瓶轴转动；单独绕工具轴转、或固定法兰XYZ改姿态，都可能让瓶盖绕偏心轨迹运动。

螺纹导程未知时，不把经验升高量当成测量值，更不能通过持续追加上提来拉断约束。根据瓶盖相对瓶颈的变化选择有限旋转和小幅分离检查。每一段基于同一份已确认的起点建立绝对累计目标，避免把每次未到位的误差累加成轴向漂移；重抓后用新图核对高度与轴线，既不盲目下移，也不把指令升高当成瓶盖真实升高。

## 以接触变化划分阶段

| 阶段 | 调用与需要确认的结果 |
|---|---|
| 固定瓶身 | 原移动与夹爪工具建立接触；瓶底有支撑、瓶身稳定，旋盖空间足够。若推移瓶子，重新定位瓶盖。 |
| 夹住瓶盖 | 张爪对中、接近指垫有效接触带，再闭爪；图像和开度/力矩共同支持夹住盖壁。到达闭爪目标但没有夹到物体时先修正几何。 |
| 有限旋转 | 两手通过瓶子产生机械约束时用原 `move_both`，固定臂保持已验证目标，旋盖臂执行有限目标。比较瓶盖图案、指垫和瓶身标签：盖随手转、身不跟转才支持有效旋松。 |
| 回腕重抓 | 回转范围不足时先松开旋盖爪，在盖与手已分离后退出并回腕，再接近重抓；固定臂继续稳住瓶身。不能夹着盖反向回腕抵消前一段，也不能只验证回腕终点而忽略中间净空。 |
| 取盖 | 有旋松依据后小幅试提，核对盖与瓶口是否出现间隙、瓶身是否被带起。仍有连接或支撑关系不明时继续判读，不只根据角度计数宣布打开。完全脱离后再横移离开瓶口。 |
| 放置与验收 | 将盖送到可支撑位置，留意倾斜夹指的最低点及开爪后的附着；确认盖留在支撑面，瓶身稳定后松开固定爪并撤离。新帧应显示敞开的瓶口、盖已分开、双爪脱离且物体稳定。 |

阶段由现有 `client / phase` 串联原 primitive，动作结束一次返回实际位姿、误差、夹爪变化、故障和三视图；完整记录保留在同一阶段目录。已检查的无接触回腕路径可以连续执行，重抓、提离、释放等改变接触关系处需要新观察后再决定后续动作。当前 primitive 插值的是关节轨迹，不能把上述离散几何目标称为已实现笛卡尔螺旋轨迹或力控旋盖。除端点可达和扫掠净空外，还应利用现有 FK 检查段内接触中心与瓶轴的偏离，必要时缩小分段；端点绕轴正确不保证途中保持同一约束。

## 异常与复用边界

瓶身跟转、瓶盖在指间滑动、瓶子被推移或提起时，取消依赖旧接触关系的后续动作，先恢复可观察的稳定支撑再调整。对中或接触带错误不能靠重复闭爪、增大驱动力矩解决；夹爪报告的N·m也不是瓶盖上的旋紧/旋松转矩。

一段动作只执行了一部分时，先读阶段记录和当前反馈，按已完成的开爪/移动结果恢复；不换证据身份重放整段。实际姿态明显不同于请求时，即使故障位为0，也应核对完整状态与场景，不能继续使用请求姿态推算持物关系。人员进入当前回转区域时暂停后续动作，待新观察确认净空再继续。

瓶型、盖径、螺纹、夹具、左右角色、相机安装和场景位置变化后，共用上述接触判断与几何方法，重新确定物理参数、回转范围、开度和力度。已有成功过程不是这些参数的默认模板。
