# 持笔书写与压纸

方法复用原 `observe`、`move_left/right` 和夹爪工具；字形、纸面、笔尖和任务坐标保存在本次证据中，不另写一套运动控制器。首次实测来自 [.56 的 ACE 任务](../../../evidence/2026-09-14/host-10.169.21.56/write-ace-evening/README.md)：左手压纸、右手书写，最后两臂让开后ACE清楚可辨。一次成功不代表跨设备或重复成功率已验证。

## 几何与接触

1. 区分真实笔尖、黑色活动夹指、固定灰色支架和相机。固定支架可以作为多个姿态中的刚体特征，不能当作夹持中心或笔尖 TCP。薄笔尖的零深度不能用边缘背景深度冒充，使用相邻有效前景外推时注明不确定性。
2. 笔在夹爪中的位置和方向决定 link6 到笔尖的刚体关系。换抓点、滑动或被顶转后旧关系失效，先重新定位；只增加夹持力不能恢复旧 TCP。靠近笔尖夹持可缩短外伸，但具体位置需留出实际笔尖和夹具空间。
3. 确定纸面方向后，将笔迹平面点换算为该臂 link6 目标。相机拟合残差不能代表接触高度或绝对精度。先在计划字形的起点写短线，抬起并退到视野外，以真实墨迹确认高度与方向，再继续有限笔画。
4. 固定书写姿态，将曲线拆成适当的小段，依原工具做 IK 与有限轨迹；断开的笔画之间抬笔。高度随纸面坡度变化，不能把某一点刚好出墨当作整张纸高度都准确。本次小段约8–10mm只是一次实测选择，不是其他设备默认参数。

## 左手固定与整体占位

压纸目标是限制纸的平移和转动。夹爪可以张开，让靠纸一侧的夹指压纸边，同时把整个左腕放在纸外；不要求夹具中心在纸上。

检查两臂整套附件，包括腕部相机、固定支架、线缆和笔尾。笔尖与压纸点分开不代表两套夹具分开。019 原始录像显示右夹具/笔尾进入左手附件空间，笔被顶转且没有出墨；故障码仍是0，因此反馈正常不能排除实际接触。该动作仅保留为失败证据。

## 验证与录像

每个字母或有限笔画后让出视野，检查墨迹是否连续、笔画是否连通、字形方向与顺序是否正确，以及纸和笔是否移动。完整状态、工具返回和实际墨迹分别保存。遇到非预期接触先取完整状态和录像，按实际原因调整，不能把接触产生的系统偏差解释为普通跟踪误差。

录像使用 [动作录像 skill](../../wcx-agilex-action-video/SKILL.md)，保留失败和纠正阶段。最终验收以撤离后的实物图像为依据，不能在图片或视频上补画字母。
